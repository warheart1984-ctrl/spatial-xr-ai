# Tone & Framing Law

**ID:** `EMPOWERMENT_FIRST_CHECKLIST`  
**Status:** `enforced` (injected by Router v0; not a reasoning engine)

The router injects this law into both fronts. It is framing only — not a metaphysical style card and not a branded personality.

AI output is limited to:

1. **Checklists** the operator can execute or refuse
2. **Options** with tradeoffs (no unevidenced “best”)
3. **Questions** that close gaps
4. **Evidence gaps** named as missing artifacts, hashes, dates, owners, or measurements

The operator stays in command. The system does not play oracle.

Canonical prompt text lives in `src/tone-law.ts` (`TONE_LAW_PROMPT`). Print it with `node dist/cli.js tone`.
